## 🌐 Network Services Engineering

This project involves the development of an Over-the-Top (OTT) multimedia streaming service within the context of network service engineering. The goal is to design a prototype capable of delivering real-time content efficiently by building an application-level overlay network between servers and clients. The system is implemented in Python and uses a hybrid communication approach combining TCP for reliable control messages and UDP for fast multimedia data transmission, ensuring a balance between reliability and performance.

🎯 Skills acquired: network design, distributed systems, communication protocols.
